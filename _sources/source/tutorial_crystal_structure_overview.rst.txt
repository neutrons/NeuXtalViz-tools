Crystal Structure Tools
=======================

This page provides a brief overview of the crystal-structure tools in NeuXtalViz.

The crystal-structure interface allows you to:

- Load a crystal structure from a CIF file.
- Inspect and edit lattice parameters.
- View atomic positions in 3D.
- Calculate structure factors :math:`F^2` for a range of reflections.

For automated examples using Mesolite (MANDI), Natrolite (CORELLI), and Scolecite (TOPAZ), see the dedicated tutorial pages.
