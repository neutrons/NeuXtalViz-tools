NeuXtalViz package
==================

NeuXtalViz (*new-crystal-vis*) is a toolkit for neutron single-crystal diffraction analysis and visualization.

Features
--------
- UB matrix calculation
- Peak indexing and integration
- Volume slicing
- Experiment planning
