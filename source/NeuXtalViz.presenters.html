NeuXtalVizPresenter: Presenter class for connecting the view and model in NeuXtalViz.

This module defines the NeuXtalVizPresenter class, which acts as the mediator between the user interface (view) and the underlying data/model logic. It handles user actions, updates the view based on model state, and manages status/progress reporting for the main visualization window.

activate_workspace_complete(result)[source]#

Refresh lattice/display state after a new workspace is activated.

Re-enables automatic color limits so the upcoming redraw recomputes vmin/vmax from the newly activated workspace’s own data, rather than carrying over manual limits left behind by whatever workspace was active before – which may have had a wildly different data range. Also forgets the cached 3D camera position, so the upcoming redraw refits/re-centers the view on the new workspace’s data instead of reapplying a camera position framed for whatever workspace was active before. For a real-space (delta-PDF) workspace, also defaults the colormap to “Diverging” and checks “Symmetric about Zero” – these remain normal, user-overridable controls afterward.

sync_symmetric_zero_with_opacity()[source]#

Auto-check “Symmetric About Zero” for zero-centered opacity mappings.

The “Linear Symmetric”/”Sigmoid Symmetric”/”Geometric Symmetric” opacity mappings are V-shaped around the midpoint of the (shared) color-limit range, so that midpoint needs to actually be the data’s zero for them to make sense. The 3D view has no color-limit control of its own to force that anymore (it shares the 2D slice’s), so selecting one of these checks the existing “Symmetric About Zero” box instead – connected ahead of the redraw this same combo triggers, so the newly resolved limits are already symmetric by the time it runs.
